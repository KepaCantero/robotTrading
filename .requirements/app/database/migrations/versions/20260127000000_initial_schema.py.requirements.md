## Function Signatures (Contracts)

### `upgrade() -> None`
**Pre:** Database exists and is accessible
**Post:** All tables are created with proper constraints, indexes, and foreign keys
**Raises:** sqlalchemy.exc.* on database errors
**Retry:** No
**Side Effects:** Creates 12 tables: users, api_keys, assets, portfolios, positions, trades, market_data, signals, backtests, risk_metrics, system_logs, position_states

### `downgrade() -> None`
**Pre:** All tables from upgrade exist
**Post:** All tables are dropped in reverse dependency order
**Raises:** sqlalchemy.exc.* on database errors
**Retry:** No
**Side Effects:** Drops all 12 tables

## Notes
- This is the foundational migration - all subsequent migrations depend on it
- Uses PostgreSQL-specific features (UUID, JSONB) but has SQLite fallback support
- All foreign key constraints follow naming convention: `fk_{table}_{column}`
- PositionState table uses Integer primary key (not UUID) for simplicity
- SystemLog table has no user_id - logs are system-wide
- RiskMetrics correlation_matrix uses JSON for flexible matrix storage
- Backtest parameters and results use JSON for strategy-agnostic storage
