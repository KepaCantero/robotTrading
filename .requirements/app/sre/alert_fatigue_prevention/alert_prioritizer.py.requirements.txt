# Requirements Document: sre/alert_fatigue_prevention/alert_prioritizer.py

## 1. Module Overview
Alert Prioritizer - Prioritizes alerts based on impact and urgency.

Part of Alert Fatigue Prevention (SRE Rule 20.11).
Considers multiple factors including severity, business impact,
time sensitivity, and historical patterns.

Author: AlgoTrading MVP Team
Version: 1.0.0

## 3. Core Components (Contracts)
### Public Classes
- `PriorityScore`: Dataclass for a calculated priority score with factors and explanation.
- `AlertPrioritizer`: Calculates priority scores for alerts.

### Public Methods
- `AlertPrioritizer.__init__()`: Initialize with priority weights.
- `AlertPrioritizer.calculate_priority(alert)`: Calculate priority score for an alert.
- `AlertPrioritizer.prioritize_batch(alerts)`: Prioritize a batch of alerts, sorted by priority.

### Exports
- `PriorityScore`: Priority score dataclass
- `AlertPrioritizer`: Main prioritizer class

### Priority Factors
- severity: 0.4 weight (critical=1.0, high=0.8, medium=0.5, low=0.2)
- business_impact: 0.3 weight
- time_sensitivity: 0.2 weight
- historical_frequency: 0.1 weight (inverted)
