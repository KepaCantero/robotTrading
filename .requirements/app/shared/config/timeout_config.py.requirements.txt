# Requirements Document: shared/config/timeout_config.py

## 1. Module Overview
Centralized Timeout Configuration for External API Calls.

This module provides timeout settings for all external service integrations:
- Broker APIs (Alpaca, Interactive Brokers)
- Market data providers (Yahoo Finance, Polygon, Alpha Vantage)
- Database connections (PostgreSQL, Redis, QuestDB)
- External services (MLFlow, Dagster)
- WebSocket connections

All timeouts are configurable via environment variables for deployment flexibility.

## 3. Core Components (Contracts)
### Public Classes
- `TimeoutConfig`: Centralized timeout configuration dataclass (frozen)
- `TimeoutManager`: Context manager and utilities for timeout handling

### Public Functions
- `get_timeouts()`: Get the global timeout configuration singleton
- `get_timeout(operation)`: Get timeout value for a named operation

### Properties
- `http_timeout`: Combined HTTP timeout (connect + read)
- `alpaca_timeout`: Combined Alpaca timeout (connect + read)
- `ib_timeout`: Combined IB timeout (connect + read)

### Methods
- `get_httpx_timeout()`: Get timeout dict for httpx client
- `get_aiohttp_timeout()`: Get total timeout for aiohttp client
- `from_env()`: Load timeout configuration from environment variables

## 6. Environment Variables
Pattern: `TIMEOUT_{SERVICE}_{OPERATION}`
Examples:
- `TIMEOUT_ALPACA_READ=45.0`
- `TIMEOUT_HTTP_CONNECT=15.0`
- `TIMEOUT_POSTGRES_QUERY=60.0`

## 7. Usage Example
```python
from app.shared.config.timeout_config import get_timeouts, TIMEOUTS

# Get global config
config = get_timeouts()
timeout = config.alpaca_read

# Use in async calls
result = await asyncio.wait_for(
    external_api_call(),
    timeout=config.alpaca_read
)

# Use in httpx
async with httpx.AsyncClient(timeout=config.get_httpx_timeout()) as client:
    ...
```
