# executor.py

## Purpose
Abstract base classes and concrete implementations for backtest execution with template method pattern, supporting simple, parallel, and process-based execution strategies.

---

## Type Definitions / Data Classes

### StrategyType
```python
StrategyType = Any  # Trading strategy instance (duck-typed)
```
**Validation Rules:**
- Must implement `generate_signals(quote)` method
- Should have optional `name` attribute for identification

### QuotesType
```python
QuotesType = List[Any]  # List of market data quotes
```
**Validation Rules:**
- Must not be empty (validated in `validate_inputs`)
- Each quote should be compatible with strategy's `generate_signals` method

### SignalsType
```python
SignalsType = List[Any]  # List of trading signals
```
**Validation Rules:**
- Optional - if not provided, will be generated by strategy
- Generated by iterating over quotes and calling `strategy.generate_signals`

### MetricsDict
```python
MetricsDict = Dict[str, Union[float, int, str]]  # Performance metrics
```

### ExecutorType (Literal)
```python
ExecutorType = Literal['simple', 'parallel', 'process']
```
**Validation Rules:**
- Must be one of: 'simple', 'parallel', 'process'
- Used by `BacktestExecutorFactory.create()` to select executor class

## Function Signatures (Contracts)

### `_run_backtest_process(config, quotes, strategy, strategy_name, enable_risk_envelope, result_queue) -> None`
**Pre:** config is valid BacktestConfig, quotes is non-empty list, strategy has generate_signals method
**Post:** Result put in result_queue as tuple ('success', BacktestResult) or ('error', str)
**Raises:** Catches (ValueError, TypeError, KeyError, AttributeError, IndexError) and puts error in queue
**Retry:** No
**Side Effects:** Spawns subprocess, imports SimpleBacktester, generates signals, runs backtest, puts result in queue

### `BacktestExecutor.__init__(config: BacktestConfig) -> None`
**Pre:** config is valid BacktestConfig with positive initial_capital
**Post:** Executor initialized with config, execution_count = 0
**Raises:** No
**Retry:** No
**Side Effects:** None

### `BacktestExecutor.execute(quotes, strategy, **kwargs) -> BacktestResult` (Abstract)
**Pre:** quotes is non-empty, strategy is not None, config.initial_capital > 0
**Post:** Returns BacktestResult with performance metrics, execution_count incremented
**Raises:** ValueError if inputs invalid, RuntimeError if execution fails
**Retry:** No
**Side Effects:** Calls _pre_execute and _post_execute hooks

### `BacktestExecutor.validate_inputs(quotes, strategy) -> None`
**Pre:** None
**Post:** Raises ValueError if quotes empty, strategy None, or initial_capital <= 0
**Raises:** ValueError with descriptive message
**Retry:** No
**Side Effects:** Logs debug message with quote count and strategy type

### `BacktestExecutor._pre_execute(quotes, strategy) -> None`
**Pre:** None
**Post:** Inputs validated, execution_count incremented
**Raises:** ValueError if validation fails
**Retry:** No
**Side Effects:** Calls validate_inputs, increments execution_count

### `BacktestExecutor._post_execute(result: BacktestResult) -> None`
**Pre:** result is valid BacktestResult
**Post:** None
**Raises:** No
**Retry:** No
**Side Effects:** Logs debug message with execution count and final_capital

### `SimpleBacktestExecutor.execute(quotes, strategy, **kwargs) -> BacktestResult`
**Pre:** quotes non-empty, strategy valid, kwargs can contain: strategy_name, signals, diagnostic_logger, enable_risk_envelope
**Post:** Returns BacktestResult from backtest execution
**Raises:** ValueError if inputs invalid, RuntimeError if backtest fails
**Retry:** No
**Side Effects:** Creates SimpleBacktester, generates signals if not provided, runs backtest, logs completion

### `ParallelBacktestExecutor.__init__(config, max_workers=None) -> None`
**Pre:** config is valid BacktestConfig
**Post:** Executor initialized with max_workers (None = auto, defaults to min(len(strategies), 4))
**Raises:** No
**Retry:** No
**Side Effects:** Calls parent __init__, stores max_workers

### `ParallelBacktestExecutor.execute_batch(quotes, strategies, **kwargs) -> List[BacktestResult]`
**Pre:** quotes non-empty, strategies is non-empty list
**Post:** Returns list of BacktestResult objects (may be fewer if some fail)
**Raises:** No (catches exceptions and logs)
**Retry:** No
**Side Effects:** Uses ThreadPoolExecutor to run backtests in parallel, logs errors for failed executions

### `ParallelBacktestExecutor.execute(quotes, strategy, **kwargs) -> BacktestResult`
**Pre:** quotes non-empty, strategy valid
**Post:** Returns BacktestResult from delegated SimpleBacktestExecutor
**Raises:** ValueError if inputs invalid
**Retry:** No
**Side Effects:** Creates SimpleBacktestExecutor and delegates execution

### `ProcessPoolBacktestExecutor.__init__(config, max_processes=None) -> None`
**Pre:** config is valid BacktestConfig
**Post:** Executor initialized with max_processes
**Raises:** No
**Retry:** No
**Side Effects:** Calls parent __init__, stores max_processes

### `ProcessPoolBacktestExecutor.execute(quotes, strategy, **kwargs) -> BacktestResult`
**Pre:** quotes non-empty, strategy valid, strategy must be pickleable
**Post:** Returns BacktestResult from subprocess execution
**Raises:** RuntimeError if timeout (300s) or execution fails
**Retry:** No
**Side Effects:** Spawns subprocess, waits up to 300s, terminates if timeout

### `ProcessPoolBacktestExecutor._execute_in_process(quotes, strategy, **kwargs) -> BacktestResult`
**Pre:** quotes is pickleable, strategy is pickleable, kwargs contains strategy_name
**Post:** Returns BacktestResult from queue or raises RuntimeError
**Raises:** RuntimeError if timeout or status='error'
**Retry:** No
**Side Effects:** Creates Process, starts it, joins with timeout, terminates if alive, gets result from queue

### `BacktestExecutorFactory.create(config, executor_type='simple', max_workers=None) -> BacktestExecutor`
**Pre:** config is valid BacktestConfig, executor_type in ('simple', 'parallel', 'process')
**Post:** Returns appropriate executor instance
**Raises:** ValueError if executor_type not recognized
**Retry:** No
**Side Effects:** None (factory method)

### `BacktestExecutorFactory.register_executor(executor_type, executor_class) -> None`
**Pre:** executor_type is string, executor_class is subclass of BacktestExecutor
**Post:** executor_class registered in _executor_registry
**Raises:** No
**Retry:** No
**Side Effects:** Updates class-level _executor_registry dict

## Notes
- ProcessPoolBacktestExecutor uses 300-second timeout for subprocess execution
- ParallelBacktestExecutor uses ThreadPoolExecutor (I/O-bound), ProcessPoolBacktestExecutor uses Process (CPU-bound, avoids ML library threading issues)
- Signals are generated by iterating quotes and calling strategy.generate_signals(quote) if not provided
- Factory pattern allows easy extension with custom executor types
