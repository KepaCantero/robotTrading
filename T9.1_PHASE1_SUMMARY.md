## Design Decisions

### 1. Separation from Quantstats Library
- Don't hardcode quantstats dependency
- Implement core metrics independently
- Can be swapped with quantstats if needed
- Makes testing easier without external library

### 2. Flexible Input Handling
- Accept both Decimal and float returns
- Auto-convert at entry point
- Maintain Decimal precision internally
- Return Decimal for consistency

### 3. Comprehensive Metrics Set

| Metric | Purpose |
|--------|---------|
| Calmar | Return per unit of drawdown risk |
| Stability | Smoothness of cumulative returns |
| Tail Ratio | Upside vs downside extremes |
| VaR 95% | Maximum expected loss (95% confidence) |
| CVaR 95% | Average loss in worst 5% scenarios |
| Omega | Probability-weighted gain/loss ratio |
| Sortino | Return per unit of downside deviation |
| Information | Excess return vs benchmark |
| Kurtosis | Tail heaviness (fat tails) |
| Skewness | Distribution asymmetry |

### 4. Edge Case Handling
- Zero drawdown → Calmar returns 0
- No downside returns → Sortino returns 0
- Constant returns → Stability = 1.0 (perfect linearity)
- Insufficient data → Return empty/zero appropriately

### 5. Error Resilience
- Try-except blocks for scipy operations
- NaN/invalid value detection and recovery
- Graceful fallbacks to default values
- Comprehensive logging
