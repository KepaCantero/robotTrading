## Architecture & Design

### Three-Layer Validation Pipeline

```
Input (CapacityFadeRequest)
        ↓
[Layer 1: Analyzers]
  ├─ HistoricalCapacityAnalyzer
  ├─ LiquidityHeadroom
  └─ AlphaDecayEstimator
        ↓
[Layer 2: CapacityFadeValidator (Orchestrator)]
  ├─ Coordinate analysis components
  ├─ Determine feasibility decision
  └─ Build recommendations
        ↓
Output (CapacityFadeResponse)
  ├─ FeasibilityGate (APPROVED/CONDITIONAL/REJECTED)
  ├─ Detailed analysis metrics
  └─ Recommendations
```

### Decay Models Implemented

1. **sqrt(capacity) Model** (Default):
   - Most conservative approach
   - Alpha decays as square root of capital scaling
   - Example: 5x capital → ~2.24x alpha decay

2. **Linear Decay Model**:
   - Moderate alpha decay per capital increase
   - 10% alpha loss per 2x capital scaling
   - More realistic for many strategies

3. **Empirical Historical Pattern**:
   - Based on historical fade patterns
   - ~25-35% fade per 10x capital increase
   - 3% alpha loss per 1x capital scaling

### Feasibility Decision Logic

```python
if estimated_alpha < required_alpha:
    Decision = REJECTED  # Hard gate
elif fade_pct > 40% OR liquidity_constrained:
    Decision = CONDITIONAL  # Needs monitoring
else:
    Decision = APPROVED  # Sufficient alpha with reasonable fade
```
